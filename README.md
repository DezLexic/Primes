# Playing with Primes

Just me playing around with prime numbers, making plots, and looking for patterns. This is a place to try out ideas, follow my curiosity, and see if anything interesting turns up.

Nothing too serious—no big claims or proofs, just experiments and work in progress. Some ideas might lead somewhere, and some probably won't. That's part of the fun.

The code, plots, and notes live in [`experiments/`](experiments/). Each experiment has its own README if you want to dig in or run it yourself. Python dependencies are listed in [`requirements.txt`](requirements.txt).
